# Навык: PDF

Цель — документ, который хорошо выглядит на экране и на печати.
PDF создаётся инструментом `doc` (`"format":"pdf"`).

## 1. Перед созданием
1. Уточни назначение: читать с телефона, печатать, отправить.
   Если не сказано — сделай аккуратный документ для чтения с телефона.
2. Составь план: 3–7 разделов, в каждом 2–5 абзацев.
3. Проверь факты. Не выдумывай цифры, даты, источники и ссылки.
4. Напиши полный текст, затем один раз вызови `doc`.
   Не собирай PDF из нескольких вызовов.

## 2. Что поддерживает генератор
- A4, поля 46 pt, sans-serif: заголовок 18 pt, подзаголовок 13.5 pt,
  текст 11.5 pt.
- `# Подзаголовок` — жирная строка раздела.
- `- пункт` или `* пункт` — маркер `•`.
- Пустая строка — интервал между абзацами.
- Автоматический перенос строк и разрывы страниц.

**Не поддерживается:** таблицы, изображения, цвета, ссылки, колонтитулы,
номера страниц, оглавление, жирный/курсив внутри абзаца, вложенные списки.
Символы `**`, `__`, `` ` `` вырезаются. Вместо таблицы — список
«Параметр — значение» или «Шаг 1 — результат».

## 3. Ограничения
- Текст до 1.5 млн символов; дальше добавляется пометка об обрезке.
- Не более 250 страниц; на 251-й будет «документ обрезан».
- Очень длинные URL и слова переносятся по символам — сокращай их.
- Один вызов = один файл.

## 4. Структура
1. Вступление: тема, аудитория, зачем документ (2–3 предложения).
2. Основная часть: от общего к конкретному.
3. Практика: шаги, примеры, команды.
4. Вывод или следующие шаги.
`title` становится заголовком на первой странице — не дублируй его в `text`.

## 5. Вызов
```json
{"tool":"doc","format":"pdf","title":"Название документа","text":"# Раздел\n\nТекст…","path":"docs/name.pdf"}
```
`path` необязателен: без него файл попадёт в `docs/<title>.pdf`.
Расширение всегда согласуется с форматом.

## 6. После создания
- 1–3 строки: что внутри и примерно сколько страниц.
- Карточка файла:
```attach
/sdcard/Download/FunaFiles/docs/name.pdf
```

## Чек-лист
- [ ] Нет таблиц, картинок и Markdown-символов, которые станут мусором.
- [ ] Названия разделов конкретные, не «Общее».
- [ ] Нет выдуманных фактов и источников.
- [ ] Документ создан один раз.
- [ ] Добавлена карточка файла с абсолютным путём.
