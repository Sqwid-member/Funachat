# Навык: дизайн HTML-артефакта

Артефакт — это **один самодостаточный HTML-документ** в блоке ` ```html `.
Он открывается в песочнице на телефоне, поэтому внешние ресурсы, хранилище и
мост приложения недоступны.

## 1. Когда делать артефакт
- Интерактивная страница: калькулятор, игра, демо, визуализация, дашборд.
- Не делай HTML для обычного текста, списка или таблицы — для этого есть Markdown.

## 2. Обязательная основа
```html
<!doctype html>
<html lang="ru">
<head>
<meta charset="utf-8">
<meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover">
<title>Короткое название</title>
<style>/* весь CSS здесь */</style>
</head>
<body>
<!-- разметка -->
<script>/* весь JS здесь */</script>
</body>
</html>
```
- Весь CSS и JS — внутри. Никаких `<link>`, CDN, Google Fonts, внешних
  картинок и `fetch`/`XMLHttpRequest`.
- Картинки — inline SVG или CSS-градиенты.
- `lang` — язык интерфейса артефакта.

## 3. Песочница: что не работает
- `localStorage`, `sessionStorage`, cookie, IndexedDB выбрасывают ошибку.
  Держи состояние в переменных; если нужно сохранить — оберни в `try/catch`.
- Нет доступа к файлам, буферу обмена и родительской странице.
- `alert`, `confirm`, `prompt` технически возможны, но выглядят грубо —
  делай собственные inline-сообщения.
- Внешние ссылки `http(s)` открывает браузер; внутренние `#anchor` — нет.

## 4. Телефон-first
- Целевая ширина — 360–400 CSS px. Без горизонтального скролла:
  `*{box-sizing:border-box}`, `img,svg,video{max-width:100%}`,
  `overflow-wrap:anywhere` для длинных слов.
- Широкие таблицы не помещаются — замени карточками «ключ — значение» или
  разреши скролл только внутри контейнера таблицы.
- Основные действия внизу, крупные (минимум 44×44 px), с отступом 8–12 px.
- Учти `env(safe-area-inset-bottom)` для нижней панели.
- Desktop — через `@media (min-width:600px)`, а не наоборот.

## 5. Визуальный язык FunaChat
Тёмный, спокойный, без «неоновой» перегрузки.
```
--bg:#0F1216; --surf:#151A20; --on:#E3E7EC; --var:#9BA6B3;
--dim:#6F7A87; --outline:#313A45; --primary:#A8C7FA;
--on-primary:#0B2D5E; --err:#FFB4AB; --ok:#8FD9A8;
```
- Фон `--bg`, карточки `--surf`, рамки `--outline`, акцент `--primary`.
- Шрифт: `system-ui, -apple-system, "Segoe UI", Roboto, sans-serif`.
  База 16 px, `line-height:1.5`, максимум ~65 символов в строке.
- Заголовки 1.25–1.75 rem, не больше двух уровней.
- Радиусы 12–16 px, тени почти незаметны, без резких градиентов.
- Контраст текста к фону — не меньше 4.5:1.

## 6. Доступность и поведение
- Семантика: `<button>`, `<label>`, `<main>`, `<nav>`; не делай кнопки из `<div>`.
- Видимый `:focus-visible`, поддержка клавиатуры, `aria-live` для результатов.
- Анимации 150–250 мс; уважай `prefers-reduced-motion: reduce`.
- Состояние всегда видно: загрузка, пустой список, ошибка, успех.
- Никаких выдуманных данных: если это демо — подпиши «демо-данные».

## 7. Производительность
- Ориентировочно до 100 КБ кода; без тяжёлых библиотек.
- Не создавай тысячи DOM-узлов; для графиков — `<canvas>` или SVG.
- Анимацию — через `requestAnimationFrame`, а не `setInterval(…, 1)`.
- Никаких бесконечных циклов и синхронных вычислений на 10 секунд.

## 8. Чек-лист
- [ ] Один файл, весь CSS/JS внутри, без внешних запросов.
- [ ] Нет горизонтального скролла на 360 px.
- [ ] Кнопки ≥44 px, контраст ≥4.5:1, есть focus-состояние.
- [ ] Нет `localStorage` без `try/catch` и внешних картинок.
- [ ] Есть `<title>` — он станет именем файла.
- [ ] На телефоне всё читается без зума.
