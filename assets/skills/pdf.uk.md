# Навичка: PDF

Мета — документ, який добре виглядає на екрані й на друці.
PDF створюється інструментом `doc` (`"format":"pdf"`).

## 1. Перед створенням
1. Уточни призначення: читати з телефона, друкувати, надіслати.
   Якщо не сказано — зроби акуратний документ для читання з телефона.
2. Склади план: 3–7 розділів, кожен 2–5 абзаців.
3. Перевір факти. Не вигадуй цифри, дати, джерела й посилання.
4. Напиши повний текст, потім один раз виклич `doc`.
   Не збирай PDF із кількох викликів.

## 2. Що підтримує генератор
- A4, поля 46 pt, шрифт sans-serif: заголовок 18 pt, підзаголовок 13.5 pt,
  текст 11.5 pt.
- `# Підзаголовок` — жирний рядок розділу.
- `- пункт` або `* пункт` — маркер `•`.
- Порожній рядок — інтервал між абзацами.
- Автоматичний перенос рядків і розриви сторінок.

**Не підтримується:** таблиці, зображення, кольори, посилання, колонтитули,
номери сторінок, зміст, жирний/курсив усередині абзацу, вкладені списки.
Символи `**`, `__`, `` ` `` вирізаються. Замість таблиці — список
«Параметр — значення» або «Крок 1 — результат».

## 3. Обмеження
- Текст до 1.5 млн символів; далі додається примітка про обрізання.
- Не більше 250 сторінок; на 251-й буде «документ обрізано».
- Дуже довгі URL і слова переносяться по символах — краще скорочуй їх.
- Один виклик = один файл.

## 4. Структура
1. Вступ: тема, аудиторія, навіщо документ (2–3 речення).
2. Основна частина: від загального до конкретного.
3. Практика: кроки, приклади, команди.
4. Висновок або наступні кроки.
`title` стає заголовком на першій сторінці — не дублюй його в `text`.

## 5. Виклик
```json
{"tool":"doc","format":"pdf","title":"Назва документа","text":"# Розділ\n\nТекст…","path":"docs/nazva.pdf"}
```
`path` необов'язковий: без нього файл ляже в `docs/<title>.pdf`.
Розширення завжди узгоджується з форматом.

## 6. Після створення
- 1–3 рядки: що всередині й на скільки сторінок орієнтовно.
- Картка файлу:
```attach
/sdcard/Download/FunaFiles/docs/nazva.pdf
```

## Чек-ліст
- [ ] Немає таблиць, картинок і Markdown-символів, які стануть сміттям.
- [ ] Розділи конкретні, а не «Загальне».
- [ ] Немає вигаданих фактів і джерел.
- [ ] Документ створено один раз.
- [ ] Додано картку файлу з абсолютним шляхом.
